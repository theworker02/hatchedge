# hatchedge

Hatch identifiers and edge tokens for idempotent workflows.

**Site:** https://theworker02.github.io/hatchedge/

## Install / run

```bash
git clone https://github.com/theworker02/hatchedge.git
cd hatchedge
node src/cli.js
node --test
```
